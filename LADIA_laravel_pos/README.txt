LARAVEL POS - TFA1 PAGES

This package contains the POS application source files only (not Laravel framework/vendor dependencies).

SETUP:
1. Install PHP and Composer.
2. Run: composer create-project laravel/laravel pos-tfa1
3. Copy the app/, resources/, and routes/ folders from this ZIP into the pos-tfa1 project, merging folders.
4. In the project folder, run: php artisan serve
5. Open the URL shown by Artisan, usually http://127.0.0.1:8000

PAGES: /, /about, /customers, /users
The customer and user lists each contain five static sample records.
Check routes with: php artisan route:list
